# 938 – Forside

## Oppgave
Maja ville ha en egen forside; importsiden var forsiden.

## Resultat
- Ny forside på `/` med velkomst og seks snarveikort. Importer flyttet til `/importer`; meny, tom-tilstand, 404 og feilsider oppdatert.
- 114 filer, 2823 tester, 24 e2e, lint, tsc, format og build grønne. Spec 6-4e, epics og README oppdatert.

## Åpne punkter
- Forsiden viser ikke data (denne uka, sist åpnet); det kan komme i designet i Epic 7.
