- (event) PRD startet i Fast path. Kilder: product-brief.md (oppdatert 279712a), research-og-avklaringer.md, tilbakemelding-product-brief.md, sensorveiledning del 1
- (decision) Innsats kalibrert som soloprosjekt i emne (IBE160): PRD holdes kort (ca. 2-4 sider), detaljer i addendum
- (decision) Dokumentspråk norsk og prosjektnavn RecipeMate, satt i _bmad/custom/config.toml, fordi briefen og brukergrensesnittet er på norsk
- (decision) Ingen konto i v1; lokal lagring. Begrunnelse: enkel kjøring for sensor og færre personopplysninger
- (decision) Import støtter sider med schema.org Recipe (JSON-LD), norsk og engelsk; tydelig feilmelding og manuell innlegging ved feil
- (decision) Skaleringsregler og 10 eksempler med fasit fra product-brief er bindende akseptkriterier
- (decision) Forbedringsforslag bak grensesnitt med mock som standard; ekte LLM via nøkkel i .env
- (decision) Plattform: webapp, mobil-først responsiv for bruk på kjøkkenbenken
- (decision) Brukerreiser for to personaer: student som lager mat til seg selv og venner, og forelder i familie på fem
- (decision) Valgte forbedringsforslag lagres på oppskriften og vises merket; originalen endres ikke
- (decision) En oppskrift ligger i maks én mappe; favoritt er et eget merke, ikke en mappe. Begrunnelse: enklere datamodell og UI
- (decision) Manuell innlegging via enkelt skjema (tittel, porsjoner, ingredienser og steg én per linje) med samme parsing og skalering som import
- (change) Utkast til prd.md (16 FR, 7 NFR, 3 UJ) og addendum.md (stack, forkastede alternativer, KI-kontrakt, testdata) skrevet
- (assumption) Porsjonsantall 1-50; duplikat-import gir beskjed; slettet mappe etterlater oppskrifter uten mappe; lokale/interne adresser avvises ved import
- (event) Forenklet finalisering for soloprosjekt: input-avstemming mot brief, research og tilbakemelding gjort uten egne reviewer-agenter; reviewer gate hoppet over, kan kjøres med bmad-review senere
- (change) Nytt krav FR-17 Avkrysning under matlaging lagt til etter UX-valg; antakelse: avkrysning lagres ikke
